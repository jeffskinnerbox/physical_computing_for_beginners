# Physical Computing for Beginners
[ELL-W105: Physical Computing for Beginners](https://www.makersmiths.org/event-6785489)

## Original Description
Physical computing is a practical way of making software and hardware work together
using key tools like microcontrollers, sensors, and actuators.
It lets a computer system sense the real world and react to it.
There are many examples where physical computing concepts are used,
like robots, drones, self driving cars, home automation, wearable technology, electronic arts, etc.

This course is intended to introduce young makers to some of the components
that make up physical computing and show them how to create useful or creative things with them.
The will learn how to use a version of Python specifically intended for microcontrollers call CircuitPython.
The will learn how to program the microcontroller to communicate with breakout boards containing
motion, distance, position, etc. sensor and actuators like DC motors, servo motors, etc.

They will learn by doing hands-on small projects via 6 classes,
each build on what they learn in previous classes.
In the course, they will be train on several tools that will empower them to work independently, at home.
The will be encouraged to research on-line for project ideas,
replicating and expand on other peoples designs.

Students can expect to do project using components like:
Raspberry Pi Pico 2W microcontroller,
Ultrasonic Range Sensor,
Micro Servo Motor,
Dual H-Bridge Motor Driver Controller,
N20 DC Motors,
9-DOF IMU,
Rotary encoders,
240x135 color TFT display.

The course is intended for high schoolers or 6 to 8 grader with a parent.
The course assumes some basic coding experience, ideally with Python.
Everyone should have there own laptop.
Everything they need will be on their laptop and the microcontroller, and day one they will be shown how install needed tools.
There will be a cloud site where they can pull down working code if need (leave no soldier behind).
Instructor will having their own laptop, projected on a screen, so students can follow along.

Classes planned to start Tuesday Sept 1st, 6:30pm, at Makersmiths Leesburg.

## Description In Public Announcement
Physical computing is a practical way of making software and hardware work together using key tools like micro-controllers, sensors, and actuators.
It lets a computer system sense the real world and react to it.
There are many examples where physical computing concepts are used, like robots, drones, self-driving cars,
home automation, wearable technology, electronic arts, etc.

This course is intended to introduce young makers to some of the components that make up physical computing
and show them how to create useful or creative things with them.
Participants will learn how to use a version of Python specifically intended for microprocessors called CircuitPython.
They will learn how to program the microprocessor to communicate with breakout boards containing
motion, distance, position, light, etc. sensor and actuators like DC motors, servo motors, etc.

They will learn by doing hands-on small projects via 6 classes, each class will build on what they learn in previous classes.
In the course, participants will train on several tools that will empower them to work independently at home.
They will be encouraged to research on-line for project ideas, replicating and expanding on other people's designs.

Students can expect to do projects using components like: Raspberry Pi Pico 2W micro-controller,
Ultrasonic Range Sensor, Micro Servo Motor, Dual H-Bridge Motor Driver Controller, N20 DC Motors,
9-DOF IMU, Rotary encoders, and 240x135 color TFT display.

The course is intended to serve High School Students (grades 9-12).
Middle School students in grades six through eight may participate, but they must be with a parent.

The course assumes some basic coding experience, ideally with Python.

Each student must bring a Windows 11 laptop that is Internet-enabled and the user has administrator rights.
Everything students need will be on their laptop and the microcontroller.
In the first class, students will be shown how to install needed tools.
There will be a cloud site where they can pull down working code if needed.
The instructor will have their own laptop, projected onto a large screen, so students can follow along.

This course will meet in the basement electronics shop at the Leesburg location.
