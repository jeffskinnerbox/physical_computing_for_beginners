Meet the Hardware

The H-Bridge: How One Chip Reverses a Motor

  • Your Pico's GPIO pins can only push current one direction, at low voltage — not enough to drive a real motor, and no way to reverse it.
  • An H-bridge is a small switching circuit — named for its shape, an “H” with the motor as the crossbar — that flips which pair of switches is closed to reverse current through the motor.
  • The DRV8833 packs two complete H-bridges onto one board, one per motor, using locked-antiphase control: two PWM pins per motor, driven in opposite phase.
  • In code, that's hidden behind one simple number — .throttle, from -1.0 (full reverse) to 1.0 (full forward), with 0.0 actively braking.
A First Engineering Lesson

50% Duty Cycle Is Not 50% Speed

A PWM signal tells the motor how much power to send — but real hardware eats into that number before any of it becomes motion:

  • Stall torque — a motor needs a minimum voltage just to overcome friction and start moving at all
  • Gearbox & wheel friction — mechanical drag that never shows up in the code
  • Voltage sag — a loaded 9V battery delivers less than its rated voltage

Why this matters

This project caps throttle with a MAX_THROTTLE constant — to limit current draw and protect the hardware, not to set a precise speed. The engineering mindset means designing around what the hardware actually does, not what the number on paper says it should do.

What the code ASSUMES: went 35.0 cm, straight ahead What actually happened: went 30.5 cm (say), drifted 4 cm left

Nothing flows back from the car to the code. This is dead reckoning — and discovering why it drifts, first-hand, is the whole point of the Independent Work.

Errors Don't Cancel — They Stack

A Commanded Square vs. What Actually Happens

COMMANDED square ACTUAL path (errors accumulate) start/end start end (never closes) +-----------+ +----------. . | | | `. | <- gap between | | | \ | start and end | 35 cm | | `--+ | = accumulated | | | | | error +-----------+ +-------------------+ ' side 1 long, turn 1 short, side 2 curves... each move starts from where the LAST one ended up

You told the car to go exactly 35 cm. Every side and every turn is a little off — and each move starts from wherever the last one actually ended, not where it should have. That gap is the price of never checking.

Phase 3 — Wheel Odometry

Giving the Car a Way to Measure Itself

What it senses

  • A Slot Type IR Optocoupler at each wheel reads the encoder disc molded into the chassis kit's wheels
  • Each tooth interrupts the beam once per slot — debounced ticks, the same fix Class 1's button/encoder needed
  • Tick count → revolutions → distance → speed in cm/s, once per wheel

The catch

  • One optocoupler tells you that the wheel moved — not which way
  • A tick is a tick either direction the disc spins
  • So direction is borrowed from motor_driver.py's last-commanded direction — a reasonable stand-in, but it assumes the wheel is actually obeying that last command
Phase 4 — Rover Status Website

The Pico Hosts Its Own Website

  • The Pico's WiFi radio broadcasts its own network — access point (AP) mode — no classroom router, no internet, at all.
  • It runs a tiny HTTP server serving /data.json (live wheel speed & direction) and a page that polls it twice a second.
  • This site is built small on purpose — every later class adds more to this same site rather than starting a new one.

The real mission

Spinning a wheel by hand only proves the plumbing works. The actual goal is a website that updates while the rover drives itself — no hand ever touching a wheel — speeds and direction changing live, straight from the car's own behavior.

Looking Ahead

Wheel Feedback Isn't the Whole Answer

Matching wheel speeds is not quite the same as going straight — if one wheel slips, both wheels can still report the same speed while the car veers. Nothing here measures which way the car is actually pointing.

Next class's IMU adds an outer loop that watches heading, wrapped around today's inner loop that watches the wheels — one more sense the car needs before it can reliably steer itself around obstacles.
