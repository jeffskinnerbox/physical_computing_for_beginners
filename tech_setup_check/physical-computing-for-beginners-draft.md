
# Physical Computing for Beginners
Physical computing is a practical way of making software and hardware work
together using key tools like micro-controllers, sensors, and actuators. It lets a
computer system sense the real world and react to it. There are many examples
where physical computing concepts are used, like robots, drones, self driving
cars, home automation, wearable technology, electronic arts, etc.

This course is intended to introduce young makers to some of the components
that make up physical computing and show them how to create useful or
creative things with them. Participants will learn how to use a version of Python
specifically intended for microprocessors. They will learn how to program the
microprocessor to communicate with breakout boards containing motion,
distance, position, light, etc. sensor and actuators like DC motors, servo motors,
etc.

This is designed as a hands-on small projects workshop involving six sessions.
Each session will build on what was learned in previous sessions. In the course,
participants will be trained on several tools that will empower them to work
independently, at home. They will be encouraged to research on-line for project
ideas, replicating and expanding on other peoples' designs.

Participants can expect to use components like: Raspberry Pi Pico W micro-
controller, Ultrasonic Range Sensor, Micro Servo Motor, Dual H-Bridge Motor
Driver Controller, Accelerometer+Gyroscope 6-DOF IMU, Rotary encoders, and
240x135 color TFT display.
